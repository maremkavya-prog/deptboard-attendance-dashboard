# DeptBoard — Attendance & Results Dashboard

## Run locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the localhost URL shown in the terminal.

## Build
npm run build

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload/push this project.
3. Open Vercel and sign in with GitHub.
4. Import the GitHub repository.
5. Click Deploy.
6. Vercel will provide the live URL.

## Features
- React + Vite
- Responsive/mobile layout
- Dashboard stat cards
- Recharts subject performance chart
- Attendance pie chart
- Search and sorting
- Students with attendance below 75% highlighted
- Student details modal
- Edit marks using useReducer
